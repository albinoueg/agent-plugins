# Projeto VERA — Validação de Evidências e Registros de Atividades

Repositório da Agent Skill **VERA**, desenvolvida para auditoria, rastreabilidade e validação técnica de demandas no Redmine e GitLab com mensuração em Unidades de Serviço Técnico (UST).

---

## Instalação Rápida via `skills.sh` (`npx skills add`)

Você pode instalar a skill VERA diretamente no seu agente de codificação de IA favorito (OpenCode, Claude Code, Cursor, Windsurf, Antigravity, etc.) utilizando a CLI oficial do ecossistema [skills.sh](https://skills.sh):

### Instalação no projeto atual (local):
```bash
npx skills add https://github.com/<SEU_USUARIO>/<SEU_REPOSITORIO> --skill vera
```

### Instalação para todos os projetos (global):
```bash
npx skills add https://github.com/<SEU_USUARIO>/<SEU_REPOSITORIO> --skill vera --global
```

Para atualizar no futuro para a versão mais recente publicada:
```bash
npx skills update
```
