# Diretório de Exemplos (`examples/`)

> **Status (`v0.1.0`):** Diretório preparado estruturalmente. Casos de uso completos, payloads simulados e relatórios de exemplo serão adicionados gradualmente a partir da versão **`v0.2.0`** conforme o [`ROADMAP.md`](../ROADMAP.md).

---

## 1. Propósito deste Diretório

Este diretório destina-se a armazenar exemplos ilustrativos e dados **100% fictícios e anonimizados** para demonstrar o funcionamento esperado da skill **VERA**, apoiar testes de validação e orientar usuários sobre os formatos de entrada e saída.

---

## 2. Conteúdo Planejado para Versões Futuras

- **Exemplos de Catálogos Sintéticos (`v0.2.0`):** Fragmentos fictícios demonstrando o preenchimento do schema dos catálogos Economia e CAST.
- **Payloads de Evidências do GitLab (`v0.3.0`):** Exemplos de JSON contendo metadados de commits, branches, Merge Requests e resumos de *diffs*.
- **Payloads de Tarefas do Redmine (`v0.4.0`):** Exemplos de JSON representando issues, descrições e apontamentos de atividades.
- **Cenários de Validação (`v0.5.0`):** Casos demonstrando:
  - Tarefa com *Evidência Verificada* completa;
  - Tarefa vinculada por *Inferência Técnica*;
  - Tarefa com *Informação Ausente* (inconsistência).
- **Relatórios Modelo Renderizados (`v0.6.0`):** Exemplos completos de relatórios Markdown finais com memória de cálculo de UST.

---

## 3. Regra de Privacidade e Segurança

Nenhum arquivo inserido neste diretório poderá conter dados reais de projetos internos, nomes de servidores privados, códigos-fonte proprietários, nomes reais de colaboradores ou tokens de autenticação.
